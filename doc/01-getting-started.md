# Getting Started

## What is KTest?

KTest is a utility for defining and executing Kafka message test cases. It allows you to:

- Send sets of messages to topics
- Check for the presence or absence of messages in topics
- Disable in-progress messages
- Parameterize message content with scripting

Test case sets can be executed sequentially or in parallel, and a JUnit-format report is produced at the end of execution.

## Prerequisites

- **Java**: Linux OS (for precompiled binary) or JDK 25 or later (for .jar version)
- **Kafka**: A running Kafka cluster
- **Schema Registry** (optional): For Avro and/or JSON schema validation

## Installation

Download the latest `ktest` Linux binary or `ktest.jar` from the project releases and place it in your working directory.

## First Test in 5 Minutes

### Step 1: Create Configuration File

Create a `ktconfig.yml` file with your Kafka broker configuration:

```yaml
registries:
  - name: my_registry
    url: http://localhost:8081
brokers:
  - name: local_broker
    bootstrap.servers: localhost:9092
    registry: my_registry
environments:
  - name: dev
    onStart: info("Dev environment active")
```

### Step 2: Create Test Case File

Create a `ktestcase.yml` file with your first test case:

```yaml
name: "Hello World Test"
steps:
  - name: "Send Message"
    broker: local_broker
    topic: test-topic
    action: SEND
    record:
      key: |
        message: "Hello World"
      value: |
        attribute1: "Hello"
        attribute2: 42
  - name: "Verify Message"
    broker: local_broker
    topic: test-topic
    action: PRESENT
    record:
      key: |
        message: "Hello World"
```

### Step 3: Run the Scan (Optional)

You can scan an existing topic to extract a sample test case:

```bash
ktest scan -e dev -i "test-topic@localhost:9092"
```

This creates a `ktsample.yml` file with the extracted sample.

### Step 4: Execute the Test

Run your test cases:

```bash
ktest srun -e dev
```

or

```bash
java -jar ktest.jar srun -e dev
```

A JUnit report (`ktreport.xml`) and a matrix summary (`ktmatrix.xlsx`) are generated by default.
