# Math Functions

## abs

Returns the absolute value of a number.

| Parameter | Description  |
|-----------|--------------|
| `number`  | Input number |

**Example:** `abs(-3.14)` → `3.14`

## ceil

Returns the least integer value >= to given number.

| Parameter | Description  |
|-----------|--------------|
| `number`  | Input number |

**Example:** `ceil(3.14)` → `4`

## floor

Returns the greatest integer value <= to given number.

| Parameter | Description  |
|-----------|--------------|
| `number`  | Input number |

**Example:** `floor(3.14)` → `3`

## max

Returns the maximal value of 1 or more numbers.

| Parameter | Description        |
|-----------|--------------------|
| `...`     | Numbers to compare |

**Example:** `max(5, -2)` → `5`

## min

Returns the minimal value of 1 or more numbers.

| Parameter | Description        |
|-----------|--------------------|
| `...`     | Numbers to compare |

**Example:** `min(5, -2, 0)` → `-2`

## pow

Returns the value of the 1st number raised to the power of the 2nd.

| Parameter  | Description |
|------------|-------------|
| `base`     | Base number |
| `exponent` | Exponent    |

**Example:** `pow(2, 8)` → `256`

## round

Returns the nearest integer, rounding half away from zero.

| Parameter | Description  |
|-----------|--------------|
| `number`  | Input number |

**Example:** `round(2.43)` → `2`

## sgn

Returns the sign of the number (-1, 0 or 1).

| Parameter | Description  |
|-----------|--------------|
| `number`  | Input number |

**Example:** `sgn(-9.63)` → `-1`

## sqr

Returns the square root of the number.

| Parameter | Description  |
|-----------|--------------|
| `number`  | Input number |

**Example:** `sqr(2)` → `1.4142135623730951`
