# Hex Functions

## hex2int

Returns the integer value of an hexadecimal string.

| Parameter | Description        |
|-----------|--------------------|
| `hex`     | Hexadecimal string |

**Example:** `hex2int("7fff")` → `32767`

## int2hex

Returns the hexadecimal representation of number.

| Parameter | Description   |
|-----------|---------------|
| `number`  | Integer value |

**Example:** `int2hex(32767)` → `"7fff"`
